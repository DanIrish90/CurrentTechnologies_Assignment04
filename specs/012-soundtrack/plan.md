# Implementation Plan: Continuous Soundtrack

## Summary

Use the complete provided song as one application-level background music session. Start it once when the Pygame window starts, loop it continuously, and keep the music lifecycle outside `GameState` so game-over restart can recreate gameplay without restarting audio. Treat audio loading/playback failure as non-fatal and expose a readable fallback indication.

## Phase 0: Research Summary

Research decisions are recorded in [research.md](./research.md):

1. Use the existing Pygame-ce mixer as the only audio dependency and validate support for the provided Opus-in-M4A asset at runtime.
2. Keep one application-scoped music session outside `GameState`; game-over restart only recreates gameplay state.
3. Use the mixer loop facility for continuous playback and catch initialization/load failures so audio cannot prevent the game from launching.
